# M2 内容模块 · 7 天交付计划

模块归属：M2（内容管理）｜约定包：`com.ylf.cms.content`
工程形态：沿用组长 main 的**单模块**结构（`cms-agent` 一个 jar），不引入 Maven 多模块，
与 `common/config/security` 直接同工程协作，避免两套构建互相牵制。

## 背景约束（开工前已确认）

| 事项 | 结论 |
|---|---|
| 工程结构 | main 为单模块，代码全部在 `src/main/java/com/ylf/cms/<包>` |
| M1（登录/用户/权限） | 已由 M4 实现（`security/user`），M2 只调 `UserContext`、`AuthService`，不自己造登录 |
| 表结构 | `src/main/resources/sql/schema.sql` 已含 `cms_article` / `cms_category`，**以表为准**，M2 不重复建表 |
| 状态字段 | `status VARCHAR(16)`，落库用枚举名 `DRAFT/PENDING/PUBLISHED/REJECTED/OFFLINE` |
| 乐观锁/分页 | `config/MybatisPlusConfig` 已装配分页（maxLimit=200）+ 乐观锁插件，M2 直接用 |
| 审核字段填充 | `config/AuditMetaObjectHandler` 统一填 create_time/update_time/create_by/update_by |
| 分类（M3） | main 尚无 `catalog` 包；M2 先按"分类可查询、可校验启用"的轻量实现接入，M3 交付后替换 |

## 接口与错误码（沿用 common 的 ResultCode）

| 场景 | 错误码 |
|---|---|
| 并发编辑冲突 | 40900 CONFLICT |
| 当前状态不允许该操作 | 40901 INVALID_STATE |
| 资源不存在/已删除 | 40400 NOT_FOUND |
| 数据已存在（同分类同名） | 40902 DUPLICATE |
| 删除用户时账号下仍有稿件 | 40903 IN_USE |
| 越权操作他人数据 | 40301 NOT_OWNER |
