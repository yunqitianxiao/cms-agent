# 界面布局约束

采用 ui-ux-pro-max 的可访问性、层级和响应式原则，保留 Thymeleaf 与原生 CSS/JS 技术栈。

## 位置怎样计算

设视口宽度为 W，侧栏 S=232px（W≤900px 时 S=0），外边距 G=clamp(16px,0.021W,36px)。主区内容宽度 C=min(W−S,1552)−2G。

统计卡四列时列宽为 (C−3×20)/4。C≤1000px 改为两列；小屏间距为12px。文章筛选栏采用 auto-fit，单控件至少152px，列数 n=floor((可用宽度+12)/(152+12))；控件均分剩余宽度，操作按钮独占末行，避免随机换行。

两栏编辑页主栏至少保留可读区域，内容宽度≤1000px 时变为单栏。长表格只允许表格容器横向滚动，页面本身不能横向溢出。手机侧栏改为可展开导航。

使用4/8px间距节奏、统一40px桌面控件、44px手机触控高度；字体、颜色、焦点环、按钮状态统一。位置由Grid/Flex和容器约束计算，不用绝对坐标摆放内容。浮动助手和装饰元素仍允许定位。

验收：实际运行页面检查桌面/窄屏；检查键盘焦点、表格溢出、筛选按钮、弹窗和助手遮挡；报告使用真实浏览器截图。
